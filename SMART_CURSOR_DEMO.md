### Scenario 6: Idle Mode (Heartbeat)
**Action:** Stop moving your mouse for 5 seconds

**Animation sequence:**
```
0-5s:     Normal cursor (active)
5s:       Enters heartbeat mode
5-7s:     Pulse 1: ◉ → ⦿ → ◉
7-9s:     Pulse 2: ◉ → ⦿ → ◉
9-11s:    Pulse 3: ◉ → ⦿ → ◉
...       Continues until you move
```

**Visual Pattern:**
```
Heartbeat Cycle (2 seconds):

0.0s:  ◉        (small, dim)
0.5s:  ⦿        (expanding)
1.0s:  ⦿        (peak size, bright)
1.5s:  ⦿        (contracting)
2.0s:  ◉        (back to small)
```

**Reactivation:**
- Move mouse → Instant return to active state
- Timer resets automatically
